# C 宿主 + 纯 C ABI

`main` 与内存管理在 C 里；所有阶段以 `extern "C"` 函数暴露，通过 `contracts/qf.h` 通信，不使用 C++ ABI、异常或 RTTI 跨边界。宿主通过 `qf_host` 结构体把分配器与字符串驻留下发给各阶段，避免各语言各自持有一份内存来源。

## 考虑的方案

- **C++ 宿主**：RAII 与 STL 更省代码，但 C++ 名字修饰、异常与对象布局会把 ABI 学习变成编译器实现细节学习。
- **C# 宿主（NativeAOT）**：C# 侧体验最好，但 JVM/Python/QuickJS 的桥接仍需一层 C，等于多一层。
- **各语言各自导出 `main`**：无法合成单一入口，直接排除。

## 后果

C 侧需要手写 arena、错误码枚举与算子循环；换来的是九种语言都能无争议地实现同一份契约。
